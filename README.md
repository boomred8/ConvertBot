FileConvertBot
Telegram-бот для конвертации и обработки файлов.

FileConvertBot позволяет работать с файлами прямо в Telegram:
объединять PDF, сжимать документы, конвертировать DOCX в PDF и объединять изображения в один PDF.

Бот реализован на Python с использованием aiogram 3 и модульной архитектуры.

Возможности
Бот поддерживает следующие операции:

📄 Конвертация DOCX → PDF

📎 Объединение нескольких PDF в один

🗜 Сжатие PDF файлов

🖼 Объединение нескольких изображений в один PDF

🔄 Автоматическая обработка файлов

🧹 Автоматическая очистка временных файлов

⏳ Ограничение времени сессии

📏 Проверка размера файлов

После выбора режима пользователю достаточно отправить файл — бот автоматически выполнит обработку.

Установка
1. Клонировать репозиторий
git clone https://github.com/yourusername/FileConvertBot.git
cd FileConvertBot
2. Установить зависимости
pip install -r requirements.txt
3. Установить внешние программы
Некоторые функции используют сторонние программы.

Ghostscript
Используется для сжатия PDF.

Скачать:
https://www.ghostscript.com/

После установки добавьте программу в PATH.

LibreOffice
Используется для конвертации DOCX → PDF.

Скачать:
https://www.libreoffice.org/

4. Создать .env файл
BOT_TOKEN=ваш_токен_телеграм_бота
Токен загружается через python-dotenv. 
conver_bot


5. Запустить бота
python run.py
После запуска бот начинает получать сообщения через polling. 
conver_bot

Режимы работы
DOCX → PDF
Пользователь отправляет .docx файл, бот конвертирует его в PDF через LibreOffice.

Объединение PDF
Можно отправить несколько PDF файлов и объединить их в один документ.

Сжатие PDF
PDF файл обрабатывается через Ghostscript для уменьшения размера.

Объединение изображений
Пользователь отправляет несколько фотографий, бот собирает их в один PDF файл.
